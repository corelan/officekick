Approval policy per action

DocKick never sends document changes without this policy: auto = apply immediately, confirm = apply only after you tick it in the preview, deny = blocked with a notice.

Debug logging

When enabled, DocKick appends AI interactions and document-edit traces to (one file per day). Debug output contains document text content and full provider payloads - keep it off when working on sensitive documents.

About

Using it inside Word

  1. Open a document.
  2. Home tab → Add-ins (dropdown) → Developer Add-ins → Corelan DocKick. With the installer's --https option the button is also available directly in the Home ribbon.
  3. The pane opens on the right; the document appears in the summary line.
