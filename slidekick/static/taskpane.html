What should SlideKick do?

Simulator deck

This is SlideKick running in a normal browser against an in-memory deck. Ops are applied to the fake deck here instead of PowerPoint.

When off (default), notes are never generated or written on slides - notes actions from the model are skipped and the prompt tells the model not to produce them. Turn it on here if you want notes.

When enabled, SlideKick appends AI interactions and deck-edit traces to (one file per day). Debug output contains slide text content and full provider payloads - keep it off when working on sensitive decks.

Approval policy per action

SlideKick never sends deck changes without this policy: auto = apply immediately, confirm = apply only after you tick it in the preview, deny = blocked with a notice.

New connection

A profile pairs a content model (slide edits/generation) with an other-actions model (chat, brainstorming, advice). ★ = default profile.

About

Using it inside PowerPoint

  1. Open a deck.
  2. Home tab → Add-ins (dropdown) → Developer Add-ins → Corelan SlideKick. With the installer's --https option the button is also available directly in the Home ribbon.
  3. The pane opens on the right; the deck appears in the summary line.
