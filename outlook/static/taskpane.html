Debug logging

When enabled, MailKick appends AI interactions and document-edit traces to (one file per day). Debug output contains document text content and full provider payloads - keep it off when working on sensitive documents.

Approval policy per action

MailKick never sends email without this policy: auto = apply immediately, confirm = apply only after you tick it in the preview, deny = blocked with a notice. MailKick never sends mail.

Using it inside Outlook

  1. Select a message (or open one to compose).
  2. Home tab → Add-ins (dropdown) → Developer Add-ins → Corelan MailKick. With the installer's --https option the button is also available directly in the Home ribbon.
  3. The pane opens on the right; the document appears in the summary line.

Sessions - conversations are saved locally (in ~/.officekick/sessions) after the first exchange and named by the AI. Named content templates for replies and new mail. Type "reply using template ..." (or "new mail from template ...") and MailKick injects that template into the AI's context. Templates are stored locally on the server; nothing is ever sent automatically - reply/compose/new-mail windows are always yours to review.
